# Mirai - Tokyo 2020 Olympic Merchandise Platform

An e-commerce platform for Tokyo 2020 Olympic merchandise, targeting fans, tourists, and collectors looking for authentic memorabilia and limited-edition items.

## Overview

Mirai is inspired by Miraitowa, the official mascot of the Tokyo 2020 Olympics. The platform provides an online shopping experience for Olympic merchandise across five product categories, with user-friendly navigation, secure authentication, and an administrative dashboard for product management.

## Features

- Product catalog with 30+ items across 5 categories: apparel, accessories, limited-edition collectibles, sports equipment, and home and interior
- Shopping cart functionality for browsing and purchasing products
- Secure login and user authentication
- Admin dashboard for managing product inventory and orders
- Responsive, user-friendly design accessible across devices

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL, SQL
- **Tools:** VSCode, GitHub

## Product Categories

- Apparel — t-shirts, hoodies, yoga pants, shorts
- Accessories — keychains, tote bags, caps, phone cases, pin sets
- Limited-Edition Collectibles — signed jerseys, action figures, commemorative coins, trading cards
- Sports Equipment — yoga mats, gym bags, water bottles, running shoes
- Home and Interior — mugs, blankets, wall clocks, posters, pillow covers

## User Groups

- **Customer** — browse products, add to cart, make purchases
- **Administrator** — manage inventory, products, orders, and user accounts
- **Supplier/Vendor** — manage stock levels, product images, and descriptions
- **Customer Support** — access order history and assist customers with inquiries
